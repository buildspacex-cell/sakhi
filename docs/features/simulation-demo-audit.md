## Feature Deep Dive

### 1. Conversation Flow (`ConversationReplay`)

- **UX model:** Single-card stepper — one entry at a time, not a chat scroll.
- **Controls:** Arrow keys, Space to auto-play, speed selector (Slow / Normal / Fast / Skim).
- **Progress bar:** Linear with accent color.
- **Phase markers:** Auto-announces phase transitions inline with phase name + emotional state.
- **Friction pill:** Shows balanced / chaos / intensity / stagnation + drift % in real time.
- **Governance climax:** Final step shows the Constitution Gate card with violation details.
- **Keyboard:** Left / Right arrows to step, Space to toggle auto-play.

**Verdict:** Polished and demo-ready. The pacing + narration pause at phase transitions creates a natural story arc that holds attention.

### 2. Continuity Arc (`ContinuityArcSection` + `ContinuityMirrorCard` + `ContinuitySpineDiagram`)

- **Topic selector:** Dropdown of auto-compiled topics from journal text.
- **Metric chips:** Topic label, span days, entry count, direction, phases.
- **Mirror card:** SVG visualization with phase-colored bands, curved baseline, boundary dots.
- **Quick recap:** Start / Pivots / Current — generated by `continuityMirror.ts` with human-readable prose.
- **Spine diagram:** Full SVG with positioned event dots, facet labels, phase shading.
- **Surface gating:** Topics below classification / coherence thresholds show "Not enough continuity signal yet" — won't surface premature insights.

**Verdict:** Most differentiated feature. No other wellness app shows "your career anxiety is one unfolding story across 22 days with 2 pivots." Extremely compelling for investors.

### 3. Deep Answer & Topic Reflection (`AskSakhiSection`)

**Flow:**
1. User sends journal entry → Sakhi replies through real pipeline.
2. Turn Debug panel shows `continuity_pack` (topic, evidence, arc_compact).
3. Two buttons: **Run Deep Answer** / **Run Topic Reflection**.

**Deep Answer:**
- Takes the user's query + full topic history → LLM synthesis.
- Renders origin story, pivots, current stage, open questions.
- Shows query source attribution (provided / topic_turn_recovery / derived).

**Topic Reflection:**
- Whole-story arc analysis without requiring a specific query.
- Returns deterministic or LLM-sourced chat response.

**Async pipeline:**
1. Enable continuity policy for the person.
2. Queue reflection job.
3. Poll status (up to 60 attempts, with periodic result probes).
4. Fetch and display result.

**Debug transparency:**
- Continuity evidence snippets with timestamps and source refs.
- Arc compact signals (start / pivots / current).
- LLM model, provider, source (deterministic vs. llm).
- Full raw JSON payload in expandable details.

**Verdict:** Demonstrates *depth of understanding* — the killer pitch. An investor can type "should I push through or take a break?" and see Sakhi's answer grounded in 30 days of context with evidence citations.

### 4. Brain State Sections (Coherence, Alignment, Identity, Themes)

These sections were previously empty due to pipeline bugs (JSONB parsing, wrong SQL queries, overly strict guards). All four are now fixed:

| Section | Bug Fixed | Data Expected |
|---------|-----------|--------------|
| **Coherence** | `_parse_json()` helper for JSONB strings in `coherence/engine.py` | `coherence_score` from Day 1 (~0.70) |
| **Alignment** | Wrong `long_term->>'emotion_state'` SQL → direct `emotion_state` column in `alignment/engine.py` | `alignment_score` (0.0 expected without tasks) |
| **Identity Momentum** | Guard relaxed from specific key checks to `len(soul_state) < 2` in `identity_momentum_deep.py` | `direction`, `confidence` from Day 1 |
| **Themes** | Episodic memory fallback added in `theme_inference.py` when reflections + goals are empty | `themes_count >= 3` from Day 1 |

## Backend Architecture

### Continuity Service (`sakhi/apps/api/services/continuity/`)

| Module | Purpose |
|--------|---------|
| `taxonomy.py` | Topic taxonomy definitions |
| `thresholds.py` | Surfacing threshold configuration |
| `inference.py` | Topic inference from journal entries |
| `compiler.py` | Compiles entry tags → arcs → topics |
| `service.py` | Main service orchestration |
| `chat.py` | Chat-mode continuity responses |
| `reflection.py` | Deep reflection (async LLM synthesis) |
| `adapters.py` | Data adapters for different sources |

### Frontend API Proxies (`apps/web/app/api/continuity/`)

| Route | Backend |
|-------|---------|
| `policy/enable` | Enable continuity policy for a person |
| `policy/` | Get current policy state |
| `policy/exclude` | Exclude topics from continuity |
| `topics/` | List compiled topics |
| `arc/` | Get arc detail for a topic |
| `reflection/run` | Queue deep reflection job |
| `reflection/status` | Poll reflection job status |
| `reflection/result` | Fetch completed reflection result |

### Mirror Text Generation (`continuityMirror.ts`)

Pure-function module that generates human-readable prose from arc data:

- `makeMirrorTitle()` — "Career Anxiety — One unfolding over ~22 days"
- `makeAnchorLine()` — "One continuous thread with one visible pivot."
- `makeRecap()` — Start / Pivots / Current prose with phase-aware mode classification

Phase modes: `quiet`, `active`, `steady`, `back_and_forth` — classified by element density relative to average.

## Business Potential

### What This Demo Proves to Investors

| Claim | Evidence on Page |
|-------|-----------------|
| "We understand users deeply" | 30-day replay showing Sakhi's responses evolving from generic to personalized |
| "We have a memory system" | Journal vs. Memory section — what they wrote vs. what Sakhi extracted |
| "We track life patterns" | Continuity Arc — topics compiled into storylines with phases and pivots |
| "We have constitutional AI" | Governance gate — Sakhi blocks harmful requests based on who the person *is* |
| "This isn't a chatbot" | Soul Evolution chart, friction states, identity momentum — systems no chatbot has |
| "Our responses are grounded" | Deep Reflection showing evidence citations, origin stories, deterministic vs. LLM source |
| "It works in real time" | Ask Sakhi — type anything, get a pipeline-processed response |

### Competitive Moat

1. **Continuity over time:** No competitor (Woebot, Wysa, Replika, Pi) tracks topic arcs across weeks. They have per-session memory at best.

2. **Constitutional governance:** The governance gate is unique in wellness AI. It shows Sakhi won't blindly comply — it *knows* the user's patterns and protects them.

3. **Ayurvedic intelligence:** Friction states (balanced / chaos / intensity / stagnation) based on dosha drift is a novel framework that's both culturally grounded and computationally rigorous.

4. **Deep reflection:** The ability to ask "tell me the full story of this topic" and get an LLM-synthesized narrative with evidence is a feature no competitor offers.

### Recommended Investor Demo Flow (5–7 minutes)

1. **Open:** ThreeActDemo governance story (2 min)
2. **Click** "See how Sakhi built this understanding"
3. **Auto-play conversation:** Hit play, let it run at Normal speed through 5–6 entries showing Sakhi's tone shift
4. **Pause at phase transition:** Show how the conversation adapts
5. **Scroll to Continuity Arc:** Select a topic, show the mirror card + spine diagram
6. **Ask Sakhi:** Type a question as the persona, show the reply + run Deep Answer
7. **Show Turn Debug:** Open the debug panel to show evidence / grounding

## Issues & Recommendations

### Current Issues

| Issue | Severity | Detail |
|-------|----------|--------|
| `showUnderstanding` defaults to `false` | Medium | The richest content is hidden behind a button. Investors might never click it. |
| Ask Sakhi lives outside collapsible | Design | It's always visible below the understanding section. If understanding is collapsed, there's no journal context visible above it. |
| No continuity data without compilation | Expected | If the JSON doesn't have a `continuity` field, the arc section shows a placeholder. Regenerated JSONs need compiled continuity. |
| Information density | Medium | There's a lot of content. An investor who doesn't know the flow may feel overwhelmed. |

### Recommendations

1. **Default `showUnderstanding` to `true`** for demo URLs (e.g., `?open=1` query param).
2. **Consider a guided walkthrough mode** that auto-scrolls through sections with narration.
3. **Verify brain state sections** render correctly with the regenerated JSON files (coherence, alignment, identity, themes).
4. **Add compiled continuity** to the persona JSON export pipeline if not already included.
